# 前奏

一只离开讨伐队伍的九界巨龙错将皇庭中祭天圣火当成主将的信标、闯入我们的世界、从世界边缘直飞至首都、对着皇庭一头栽下、直到冲破到了地心的位置、打通了和地狱的边界后消失了踪迹。时年一月、皇庭被彻底摧毁了、不愿与臣民一同撤离而直面命运的帝国皇帝也随巨龙烟消云散了。

帝国内部陷入一片混乱。王妃撤慢了一步而被地狱恶魔杀害、王储和其指挥的近卫军也被趁机发难的北方蛮族包围歼灭、宰相带着皇女逃往了他的老家天涯湾、王族也逃回了自家封地。中央军队为防止被一举歼灭、在各家将领的带领下向四方突围、逃到了诸王的领地上，在得知皇帝的死迅后都归到了各方领主的帐下。随着中央政府彻底失能，各地方政府都进入事实上的独立状态。到了八月，局势逐渐稳定下来，实际控制最多领地的皇帝外戚楠亲王在自己的封地内部宣布了面对恶魔的强大攻势大家应该再次团结起来，为了解决政府组成问题，制定新的帝国宪法，邀请各亲王于今年八月末亲临橡木林，共同商议组成新的政府。

目前前帝国境内主要分为三股势力在争夺正统，分别为新资产阶级支持的外戚楠王，老臣们和旧贵族们支持的皇叔乌亲王，在场外还有在中后期才会入场的宰相良陪着的皇帝唯一后人澜公主。

主角小队是地图上某处刚组成发迹的佣兵、为了在这乱世出人头地而选择踏上征途、在一系列机遇中提升声望加强实力、最终随着一方加入了这场制宪大战中、影响着故事的结果

# 人物

## 华丽斯-左卫的兰苗，“小军医”

自幼被宗教国的修女在兰花开放的水边捡到，带入修道院长大，从小变生得落落大方，如那日在水边将绽之兰，故得名兰苗。

法袍上缀有兰花之色，中央绘制着国教图腾，是为修道院新任见习修女的象征，一头栗色长发直到腰间，头上多出的两只猫耳诉说了她不为人知的特殊来历，温柔的眼神中充满了修女的善良，在同龄人中算是神圣魔法的佼佼者，作为这一届优秀修女，获教区牧首赐天山陨铁杖芯，修道院圣树枝木的神圣法杖一根，前往王廷进行成年旅行。

但是乎遇天界大患，敌自天边直捣黄龙，大难之中，兰苗夹于混乱之中侥幸逃离王廷，伴着人流向南逃去，一路救死扶伤，竭心尽力，听闻她事迹的本地领主从为数不多的补给中找出了几包来自东方的咖啡，缓解了她的疲惫，从此她便爱上了这种东方饮料。

危机最初半年间，由于恶魔在原首都发迹，流窜各地少啥掳掠，各地边境均被封锁，兰苗无法回到家乡，便在领主的请求下半推半就的作为军队军医在四处奔波，为最困难的地方提供教会圣法的帮助，尽量救治伤员。但由于长时间出没一线战场，她也从对于战争的畏惧变成麻木，性格渐渐变得冷酷，救治方式从本来的不愿放过任何一个人变成了只救治能活下来的人，并且判断很少出错，人们对她的态度就从原来的纯粹尊敬爱戴变成了一种五味杂陈的无奈，都知道她已经尽力了。经历了最残酷的战场后，她再也回不到原来那样自由开朗的样子了，她现在拖着大黑眼圈，扛着包袱药品奔波在最惨烈的战场上，尽力帮助这个因各地隔绝而分崩离析的国家。筋疲力尽中，只有一杯热腾腾的咖啡能博得她浅浅一笑了。

时间一点点过去了，人们对于恶魔从上半年的艰难抵抗变为了下半年的战略反攻，开始逐渐收回被侵占的土地，清剿肆虐的恶魔，净化被侵犯的村庄，重建被摧毁的家园。在局势逐渐稳定后，兰苗也渐渐卸下了军医的担子，开始寻找回家的方法，希望回到那个养育她的地方。但求助于本地领主后得知，现在回教宗国的陆路已经彻底被恶魔摧毁了，只能依赖于水路，但是大船已经完全被军队征用，小船也完全跑不了这种远洋航线。如今要回家，只能寄希望于统一的政府重新建立，集整个帝国的力量对恶魔进行总反攻，才能有可能回去。

她觉得自己身为为数不多能留在大陆的华丽斯人应该做点什么。她开始做准备，准备物资收集信息。在从劳心劳神的战场环境中离开之后，经过充分休息的她开始找回危机之前那个优秀又奋勇拼搏的自己。上一次踏上征途是离开家，这一次踏上征途是为了回家！想到这里，那种对着未知的未来而一往无前的笑容开始重新在她脸上浮现。扛起法杖，背上行囊，目标：华丽斯！

于是她决定踏上寻找回家方法的道路。

## 奥斯弗的伊利昂•奈奈，“独身者”

奥斯弗本地贵族的二女儿，在城堡里出生，在城市内生长，在大学内学习，在城垛上科研，在工坊里工作。她的30余年的生命几乎全在这个被称为“岭南的明珠”的城市中度过。这么多年来，她对于这个诞生她、哺育她、教育她的城市本来没什么厌倦，对她来说，这里既然是世界上最完美的地方，那为什么要去别的地方呢。

多年来她一直是大学内的明星学者，在可控魔法武器的研究上居于大陆领先水平，但她对自己从不松懈，做事从来一丝不苟，及时不断取得技术突破，依旧不断努力，永远在追求自己心中的那把完美的武器，那把配的上她完美家园的完美武器，只能由完美的自己打造。

在年轻时她就被选中作为未来奥斯弗大学城的监督者，进入了大学城学习。多年来的科研生涯使得她几乎完全不在乎政治，将心力投入了可控魔力的研究之中，直到32岁时天灾将一切打乱，她必须走出大学城帮助她大姐协调民众、巩固城防、联系学者，为未来可能的防御战做准备。

在战事进入反攻阶段后，她也得以获得半分闲暇。她意识到在日夜为了家园操劳之后，她开始不觉得为了一切完美就是完美的。原来撼动世界的父亲也会一病不起，原来顶天立地的姐姐也会陷入焦虑，原来天真浪漫的小妹也能扛起责任，原来近乎完美的学者我也会无能为力。她开始怀疑自己一心扑在学术上真的有助于家族有助于国家有助于子民吗，她开始看着家族的族谱开始思考自己的未来。自己已经快要不再年轻，再拖下去不改变如果老了就是终身的遗憾

姐姐的建议是，“那你去看看吧，也是帮我去看看。多年前陪着父亲从王都回来之后我再也没有机会能再一次踏上冒险，这么多年来我一直看看这大陆现在怎样，但一直公务缠身。你帮我看看去吧，一定要安全回来，告诉我你看到了什么。“

她整理好了自己的行李，穿上了旅行风衣，穿上长靴，拿上她最引以为豪的设计——那把大学实验室出来的蓄力杖，离开了城堡。

于是奈奈踏上了探索世界的道路。

## 岭南

### 奥斯弗

“岭南的明珠”，“贸易线上的图书馆”，“学者之家”，是新岭南直隶第二大的城市。奥斯弗在被商队伊利昂家族控制以后，经过一个世纪的励精图治，在皇帝登基天下太平的年代，又在“开明伊利昂”伊利昂•李罗的管理下，它成为了实际上整个岭南的经济首都和学术首都。

位于岭南海海滨，优良的港口搭配来往不绝的商路往来，使它成为了天然的商人聚集地。为了供给商人的需求，进而推进了本地其余副产业的发展，这里成了岭南旅店密度最高的地方，成为了城市主干道最宽的地方，成为了中央地租最贵的地方。商业的聚集也促进了产业的升级。早年间，这里开设了第一家现代银行，脱胎自行业协会，发行汇票便以汇款；近几年间，这里又开设了大陆第一家股票交易行，并发行了第一支股票（但后来在天灾中被关停了）。

这里自古以来便是良港。在很久以前，在这里依旧人烟稀少的时代，标志着最先进技术的城邦居民中，有一批因对神明看法不同而被视为异端的先进学者在被迫害中选择搭乘小船环大陆离开，在环绕半个大陆之后，找到了这个地方。在古诗人的描述中，古时候的这里山清水秀如画，牛羊遍地如图，本地的原住民却不知神明。于是这些学者在这里创立了自己的学派，并向本地尚武的野蛮人传教，使这里成为了当时整个现代岭南大陆最先进的地方。

多年以后，当时的宗教学术早已没落，但留下的学堂依旧存在，并发展成了一个近封闭的城中之城，称为“大学城”。在几次大学危机之后，伊利昂家族与学者达成共识，给予大学一定的自治权利，不会强制学者们融入世俗活动，但一切需要在一位伊利昂家族成员的监督下进行。“开明伊利亚”时期得益于本人的威望，大学城和其余部分都直接由他掌控，所有事情都直接收他管辖。

经济和学术，就像一块金币的两面。在伊利昂家族多年的运筹帷幄下，开放包容的经济和自由严谨的学术同时在这片土地上绽放，互相隔离又互相补充。

作为经济首都和学术首都，其却不分担政治职能，这是很特别的。在皇帝带着他的龙骑兵团征服了将近半个大陆后，抵达奥斯弗城下，”开明伊利昂”明白自己完全无法抵抗也没必要抵抗这位强大却胸怀天下的君主，自愿打开了城门，使这里免受帝皇大炮的毁灭打击，完整的保全了下来。

在大陆南方和中部一统之后，“开明伊利昂”主动来到王廷，分享了城市的税收和最先进的人文知识，并担任了几年宫相，把最先进的治理理念从王廷传向世界，让整个世界开始慢慢接受现代政治，也悄无声息的将共和的理念传入了所有人心里。在于皇帝多年深交后，“开明伊利亚”接受了皇帝赏赐的血酒，与帝王拜为兄弟。这本来是野蛮人的仪式，却发生在最文明的两个人之间，让整个世界为之震惊。震惊之余，人们也慢慢接受，在统一的文字和宗教旗帜之下，帝国之内的民族融合开始快速发展。与皇帝的交流成功促进了民族的融合。后来伊利亚•琳琳嫁给了年轻的皇帝弟弟叶望乌，更拉近了两家人的联系。

统一之后，整个岭南被分给了皇帝年轻的弟弟，而奥斯弗则继续收伊利昂家族管辖。为了平衡地区局势，岭南的所有行政机构都被设置在了岭南偏西部的阜丘，也包括了帝国银行的总行，被统一交给帝皇的弟弟管理。但帝国银行最大的支行却被设在了奥斯弗，这更标定了奥斯弗的经济地位。

大天灾之后，帝王殡天以后，与帝王互称兄弟的“开明伊利亚”一病不起，他培植多年的大女儿、从阜丘回来的伊利亚•琳琳上任。大学城要回了自治权，也答应接受一位伊利亚姐妹监督。由于二姐奈奈志不在此，大学被交给了三妹管理。

天灾抵抗期间，由于来往商路众多，无数恶魔顺着大陆直扑过来，使奥斯弗在最初经历了数次猛烈攻击，本地在没有帝皇龙骑兵的帮助下艰难抵抗，但还是靠先进的守城武器和经营多年的基层管理脉络挺了下来。一直到阜丘战事告一段落，叶望乌亲自率领龙骑兵团前来支援，本地的恶魔才终于被驱离。后来的战事中，奥斯弗依旧尽心竭力，在伊利昂家族强大的组织里和号召力下，全城民众上下齐心，抵御天灾。在岭南重新建立防线之后，一直到进入反攻时期，奥斯弗一直都处在保护之下，从没沦陷过。

在反攻遇阻后，将要召开立宪大会时，虽然伊利亚•琳琳“奥斯弗的保护者”理所当然的和她丈夫统一战线，但背后，她也在按照她父亲的想法和家族的传承，默默影响着叶望乌，
为普通人和学者争取更多权益。
